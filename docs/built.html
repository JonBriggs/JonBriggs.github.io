Evolution of Society ↗

A long-running EPS course, co-developed with Matt Delaney, tracking technology's effect on society — from mobile phones to electric cars to generative AI. Lives at evosociety.org.

AI

Python · agents
PSIS / Ravenna Data Capture

Pulls structured applicant data out of Ravenna into clean profiles — the front end of a forward-looking, tunable math-placement model that proposes each student's next course with a confidence score for a human to review. Described conceptually only; no student data appears here or in this site's source.

JavaScript
Canvas Bookmarklet Maker

Generates small client-side tools that add the views Canvas lacks — grading-delay analytics by section, a seating-chart builder — running entirely in the teacher's own browser, talking only to Canvas's own API.

Retired

2020
COVID Prescreen

The daily health-screening tool the school ran during the pandemic.

LTI · SVG
Avatari ↗

An LTI experiment in classroom gamification: students earned points, opened chests, and collected items to dress up an avatar — the whole wardrobe rendered as layered SVGs. Playful, and genuinely fun to use.

retired
Assignment Machine

Aggregated each student's assignments across all their classes and graphed them, reading special Canvas comment codes — M: for missing, INC: for incomplete. Retired when it wasn't used enough to justify the upkeep; a candidate to revive.
